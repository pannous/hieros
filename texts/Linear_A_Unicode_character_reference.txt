Linear A Unicode character reference
====================================

DATA TYPE
This is a Unicode character reference, not a transcription of individual
Linear A tablets. It contains every assigned Linear A character in Unicode
17.0, with the literal encoded character, code point, and normative Unicode
character name.

LIMITATION / TABLET TRANSCRIPTIONS
The INSCRIBE 3D Interactive Web Viewer provides 3D models and metadata, but its
public viewer does not provide downloadable Unicode transcriptions of those
tablets. SigLA provides a scholarly, searchable corpus of Linear A documents
and sign attestations (CC BY-NC-SA 4.0), but its project description identifies
full transliteration and Unicode transcription as planned additions rather
than current tablet-level Unicode data. Consequently, this file does not claim
to reproduce or align the signs on any particular INSCRIBE model.

For tablet-level study, use SigLA's document corpus alongside the 3D viewer.
The character table below can then be used to encode signs that have secure
Unicode correspondences. Linear A is undeciphered; character names such as
AB001 and A301 are catalog identifiers, not translations.
